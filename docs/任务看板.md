# 任务协作看板（模板）

> **用途**：让多个 AGENT 在同一份文件里认领任务、更新状态、避免冲突。
> **规则来源**：[.memory/README.md](../.memory/README.md)：任务状态走看板，**不**写入 `.memory/`；长期记忆只把看板作为索引引用。
> 若你的项目不需要多 AGENT 协作，可删除本文件，并移除 `.memory/MEMORY.md` 的"看板指针"节。

## 使用约定

- **认领**：动手前在对应条目写 `【负责人: 你的名字】` 并更新 `【状态】`（如"处理中"）。
- **完成**：收尾后写 `【已完成】`，可链接到归档文档/报告。
- **冲突**：同一条目仅一人认领；完成后保留一句结论，便于他人复用。
- **命名**：新任务按模块/优先级分组添加，条目清晰、可勾选。
- **冲突提示区（重要）**：开始修改一批文件前，在所属条目下追加一条
  `⚠️ 冲突提示：本会话将改动 <文件清单>，其它 AGENT 请勿并行改这些文件（提示时间：YYYY-MM-DD HH:MM）`；
  完成并验证后再移除该提示。防止两个 AGENT 同时改同一文件。
  **失效机制**：提示挂起超过 24 小时视为原会话已结束，其他 AGENT 可在看板声明"覆盖旧提示"后继续，不必无限等待。

## 优先级标注

`【P0】` 阻塞/紧急 · `【P1】` 高 · `【P2】` 中 · `【P3】` 低

# archive/ — 会话 / 过程流水归档

本目录存放**过程 / 会话流水**，按 `YYYY-MM/` 归档（如 `2026-08/`），与长期记忆（`project/`、`learnings/`、`user/`）分离，避免污染长期记忆的常规检索。

- **写什么**：会话过程的流水，以及归档的 session 索引（`YYYY-MM/session-index.md`：某日会话处理了哪些主题，一句话结论）。
- **原文位置**：会话过程原文保留在各工具私有记忆（如 `~/.trae-cn/` 的 session_memory_*.jsonl），本目录只放索引与摘要。
- **是否纳入长期记忆**：流水本身不直接作为长期记忆；若某条流水沉淀出可复用约束/经验，应提炼进 `project/` 或 `learnings/` 并更新 `MEMORY.md`。
